# 2. プロジェクト概要
本プロジェクトは、マイコン「RA4E2 FPB」の開発手順書を作成するプロジェクトである。  
e² studioを使った組み込み開発の手順や、実際にマイコンにプログラムを書きこむ手順等を示す手順書を作成する。  
研修生が手順書を読むことにより、RA4E2 FPBとe² studioを使った開発ができるようになることを目的とする。

# 3. 要件
下記の3資料に則り、**読み手・書き手がともに迷わず運用できる**手順書を作成する。
<br>・[オリエンテーション資料](https://docs.google.com/presentation/d/176VfFL6jnZMZvnlcnzQr2OYsId6LLqgdQosq3g9RXWk/edit?slide=id.p8#slide=id.p8)
<br>・[手順書づくりの進め方_RA4E2 FPB 編](https://docs.google.com/presentation/d/1qx1VdwxyvKymWIX86opWBcbBQuqNNmiMYU0mebTjE9g/edit?slide=id.p12#slide=id.p12)
<br>・[手順書テンプレート紹介資料](https://docs.google.com/presentation/d/1Bl2NqJz9W8lAkm-M4A8aKznSpVRzpFoKyBHCuVhZBM0/edit?slide=id.p1#slide=id.p1)

また、テンプレートに則り以下の章構成で手順書を作成する。
```txt
0.概要
    0.1 この手順書でできること
    0.2 必要な機材
    0.3 前提知識・事前準備
1. 開発環境構築
    1.1 ツールのインストール
    1.2 ドライバのインストール
    1.3 インストールできたことの確認
2. シリアルターミナルの使い方
    2.1 使用するツールと接続方法
    2.2 通信設定(ポート、ボーレートなど)
    2.3 動作確認
3. プロジェクト作成
    3.1 新規プロジェクトの作成
    3.2 プロジェクトの構成(フォルダ・ファイルの役割)
4. コーディング・ビルド・書込み(RTOSなし)
    4.1 題材1:LED点滅
    4.2 題材2:ボタン入力
    4.3 題材3:UART出力
    4.4 題材4:タイマ割込み
5. コーディング・ビルド・書込み(FreeRTOS)
    5.1 FreeRTOSの導入・設定
    5.2 題材5:複数タスク
    5.3 題材6:タスク間通信
6. デバッグ
    6.1 デバッガの接続(配線図・写真)
    6.2 デバッグの開始
    6.3 ブレークポイント・ステップ実行
    6.4 変数・メモリ・レジスタの確認
7. トラブルシューティング
8. 参考資料
```
