# 4.1 LED1の点滅

RA4E2において、LED1を0.5秒間隔で点滅させる。
そのためのプログラム作成、および流し込みを行う。
なお、本題材において配線は不要である。

以下に作業手順を記載する。

1. fsp(pins)を以下のように設定するbr>

	|ピン番号|機能名|設定項目|設定値|
	|:-|:-|:-|:-|
	|P207|LED1|Mode|Output mode (literal low)|

1. fsp(stacks)を以下のように設定する<br>

	|使用するFSP|概要|備考|
	|:-|:-|:-|
	|r_ioport|マイコンのピンの入出力を制御し、信号の読み取りや出力レベルの変更を行う|プロジェクト作成時に自動追加されるため設定不要|

1. src/hal_entry.cに、下記のコードを貼り付ける。

	```c
	/* 0.5秒間隔でLED1の出力を切り替える */
    while (1)
    {
        /* LED1の出力をLowにする */
        R_IOPORT_PinWrite(&g_ioport_ctrl, LED1, BSP_IO_LEVEL_LOW);

        /* 500ミリ秒待機 */
        R_BSP_SoftwareDelay(500, BSP_DELAY_UNITS_MILLISECONDS);

        /* LED1の出力をHighにする */
        R_IOPORT_PinWrite(&g_ioport_ctrl, LED1, BSP_IO_LEVEL_HIGH);

        /* 500ミリ秒待機 */
        R_BSP_SoftwareDelay(500, BSP_DELAY_UNITS_MILLISECONDS);
    }
	```
