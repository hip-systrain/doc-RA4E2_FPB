# 4.X 課題名
冒頭に、課題を完了するまでの大まかな作業フローを記載する。

FSPモジュールの追加、ピン設定、プログラム作成、ビルド・書込み、動作確認など、必要な工程を順番に示す。
4.X.1 作るもの
課題で実現する機能と、完成時の具体的な動作を説明する。

例：LED1を0.5秒間隔で点灯・消灯させる。

# 4.X.2 プログラム
以下の順番で記載する。

1. 使用するFSPモジュール
モジュール名・用途を表で示す。
初期状態で追加済みか、新たに追加する必要があるかを区別する。

2. FSP Configuratorの設定手順
「何を実現するために、何を設定するか」を先に説明する。その後、設定場所・設定項目・設定値・操作手順を記載する。FSPモジュールの追加が必要な場合は、その手順も含める。

3. プログラム本体
hal_entry.c に記述するコードを、コピー可能なコードブロックで掲載する。

4. 使用する関数・定数・変数
コードに登場する主要な関数・定数・変数について、名前・提供元・役割を表で説明する。

# 4.X.3 ビルドと書込み
プログラムをビルドし、RA4E2 FPBへ書き込んで実行するまでの操作手順を記載する。

# 4.X.4 動作確認
実機での確認操作と、正常と判断できる期待結果を記載する。

課題に応じて、LEDの点灯状態、SW1の操作結果、Tera Termへの表示、タイマ割込みの動作などを確認する。
