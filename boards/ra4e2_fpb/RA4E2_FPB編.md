## 4.1 LED1の点滅

RA4E2 FPBに搭載されたLED1を、0.5秒間隔で点灯・消灯させるプログラムを作成する。

### 4.1.1 プログラム

#### (1) 使用するFSPモジュール

|FSPモジュール|用途|追加の要否|
|---|---|---|
|`r_ioport`|GPIOによるLED1の出力制御|不要（初期状態で追加済み）|

#### (2) LED1を制御するため、P207をGPIO出力に設定する

LED1はマイコンのピンであるP207に接続されているため、FSP ConfiguratorでP207の出力設定を行う。

1. `configuration.xml` を開き、「Pins」タブを選択する
2. 「Ports」からP207を選択する
3. `Mode`のステータスを`Output mode (Initial Low)`に変更する
4. 「Generate Project Content」を実行し、設定を反映する。

#### (3) LED1を0.5秒間隔で点灯・消灯させる

`src/hal_entry.c` の `hal_entry()` に、以下のプログラムを記述する。

```c
void hal_entry(void)
{
    while (1)
    {
        /* LED1を点灯する */
        R_IOPORT_PinWrite(&g_ioport_ctrl, LED1, BSP_IO_LEVEL_HIGH);

        /* 0.5秒待機する */
        R_BSP_SoftwareDelay(500, BSP_DELAY_UNITS_MILLISECONDS);

        /* LED1を消灯する */
        R_IOPORT_PinWrite(&g_ioport_ctrl, LED1, BSP_IO_LEVEL_LOW);

        /* 0.5秒待機する */
        R_BSP_SoftwareDelay(500, BSP_DELAY_UNITS_MILLISECONDS);
    }
}
```

**使用する関数**

※BSPはFSPに含まれる基本機能群。

|名前|提供元・定義元|役割|
|:-|:-|:-|
|`R_IOPORT_PinWrite()`|`r_ioport`|指定したピンの出力レベルを変更する関数|
|`R_BSP_SoftwareDelay()`|BSP|指定した時間だけ処理を待機させる関数|


**使用する値**

|名前|提供元・定義元|役割|
|:-|:-|:-|
|`g_ioport_ctrl`|`r_ioport`|提供元FSPの制御変数|
|`LED1`|FSP Configuratorによる生成|LED1に割り当てられたピン番号を示す定数|
|`BSP_IO_LEVEL_HIGH`|BSP|出力レベルHIGH(LEDにおいては消灯)を意味する定数|
|`BSP_IO_LEVEL_LOW`|BSP|出力レベルLOW(LEDにおいては点灯)を意味する定数|
|`BSP_DELAY_UNITS_MILLISECONDS`|BSP|上述の待機関数において、待機時間の単位をミリ秒に指定する定数|




### 4.1.3 ビルドと書込み

作成したプログラムをRA4E2 FPBで実行するため、ビルドと書込みを行う。

1. 「プロジェクト」タブよりビルドを行い、エラーがないことを確認する。
2. 「デバッグの構成」を開く
3. 「Renesas GDB Hardware Debugging」より、ビルドしたプロジェクトのデバッグを行う
4. デバッグ画面でプログラムが一時停止していれば書き込み完了
5. F8（Resume）で実行を再開する

### 4.1.4 動作確認

RA4E2 FPBのLED1が約0.5秒間隔で点滅していることを確認する（間隔は目測で良い）
